## Introduction

scans rubix cube using cv2 and solves using kociemba

## Getting Started

```bash
# Create and activate a virtual environment
python -m venv env
env\Scripts\activate        # Windows
# source env/bin/activate   # macOS / Linux

# Install dependencies
pip install -r requirements.txt

# Run the scanner
python CubeScanner.py
```

## Instructions

press Q to end the program
press S to scan the cube
press F to solve/fix once the 6 sides have been scanned

## IMPORTANT

when scanning U, B must be on top
when scanning F,L,R,B , U must be on top
when scanning D, F must be on top
